# 前端设计文档

## 1. 技术选型

| 技术 | 选择 | 版本 |
|------|------|------|
| 框架 | Flutter | 3.16+ |
| 状态管理 | Riverpod | 2.x |
| 路由 | go_router | 14.x |
| HTTP | dio | 5.x |
| 本地存储 | shared_preferences | 2.x |
| Web 构建 | flutter build web | — |

## 2. 页面结构

```
首页（底部导航）
├── 快讯页 /news
│   ├── 热点流列表
│   ├── 热搜词浮层
│   └── 每日卡片
├── 排行页 /ranking
│   ├── 综合榜
│   ├── 分类榜（Tab）
│   └── 模型详情页 /ranking/:id
├── 赋能页 /empower
│   ├── 提示词广场
│   ├── 工作流教程
│   └── 模型跳转
├── 社区页 /community
│   ├── 帖子流
│   ├── 帖子详情 /community/post/:id
│   ├── 话题圈 /community/topic/:id
│   └── 发帖页 /community/post/new
└── 我的 /profile
    ├── 收藏
    ├── 历史
    ├── 订阅管理
    └── 设置
```

## 3. 状态管理设计

### 3.1 全局状态（Riverpod）

```dart
// 认证状态
final authProvider = StateNotifierProvider<AuthNotifier, AuthState>

// 当前用户
final currentUserProvider = FutureProvider<Profile>

// 榜单数据
final rankingProvider = FutureProvider.family<List<Model>, RankingQuery>

// 帖子流
final postsProvider = StreamProvider<List<Post>>

// 热搜词
final trendingKeywordsProvider = FutureProvider<List<TrendingKeyword>>
```

### 3.2 页面状态（StatefulWidget / useState）

复杂页面内部状态（如表单、筛选条件）使用页面级状态管理。

## 4. 关键组件

| 组件 | 说明 |
|------|------|
| ModelCard | 模型卡片：名称、厂商、排名、评分 |
| PostCard | 帖子卡片：头像、标题、摘要、互动数据 |
| RankingList | 排行榜列表：排名数字、模型信息、趋势箭头 |
| HotNewsItem | 快讯条目：来源图标、标题、时间 |
| KeywordChip | 热搜词标签 |
| ModerationStatus | 审核状态标识 |

## 5. Web 适配

- Responsive Layout：手机/平板/桌面三档布局
- 底部导航在 Web 端可改为侧边栏
- 图片懒加载
- Route: `/news` → Web URL 直接可访问（SSR/预渲染可选）

## 6. 性能优化

- 列表：ListView.builder + pagination
- 图片：CachedNetworkImage
- 骨架屏：shimmer 加载动画
- 缓存：Supabase 客户端自动缓存
