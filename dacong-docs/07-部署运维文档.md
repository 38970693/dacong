## 1.1 Docker 部署（推荐）

**快速开始**:

```bash
# 1. 配置环境变量
cp .env.example .env
vim .env  # 配置必需的环境变量

# 2. 一键启动
./scripts/docker-start.sh

# 3. 健康检查
./scripts/docker-health-check.sh
```

**访问地址**:
- 客户端: http://localhost
- 管理后台: http://localhost:8080
- API: http://localhost:8000

**详细文档**: 参见 [Docker 部署文档](./deployment/DOCKER_DEPLOYMENT.md)

## 2. Supabase 部署

### 2.1 创建项目

1. 访问 https://supabase.com 创建项目
2. 获取 Project URL 和 anon/public key
3. 配置 .env：

```env
SUPABASE_URL=https://xxxx.supabase.co
SUPABASE_ANON_KEY=eyJxxx
SUPABASE_SERVICE_ROLE_KEY=eyJxxx
```

### 2.2 初始化数据库

```bash
npm install -g supabase
supabase login
supabase link --project-ref <ref>
supabase db push
```

### 2.3 部署 Edge Functions

```bash
supabase functions deploy rank-calc
supabase functions deploy moderation-trigger
supabase functions deploy push-trigger
```

## 3. VPS 部署（爬虫 + Worker）

### 3.1 服务器初始化

```bash
ssh root@your-vps-ip
apt update && apt upgrade -y
useradd -m -s /bin/bash dacong
usermod -aG sudo dacong
```

### 3.2 Python 环境

```bash
su - dacong
python3 --version
python3 -m venv ~/venv
source ~/venv/bin/activate
pip install -r requirements.txt
```

### 3.3 Systemd 服务

```ini
# /etc/systemd/system/dacong-spider.service
[Unit]
Description=DaCong Spider Service
After=network.target

[Service]
Type=simple
User=dacong
WorkingDirectory=/home/dacong/dacong-spider
Environment=PATH=/home/dacong/venv/bin
ExecStart=/home/dacong/venv/bin/python -m schedulers.jobs
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
systemctl enable dacong-spider
systemctl start dacong-spider
journalctl -u dacong-spider -f
```

## 4. GitLab CI/CD

```yaml
# .gitlab-ci.yml
stages:
  - build

flutter_build:
  stage: build
  image: cirrusci/flutter:latest
  script:
    - cd dacong-client
    - flutter pub get
    - flutter build web --release
    - tar -czf build.tar.gz build/web
  artifacts:
    paths:
      - dacong-client/build.tar.gz
```
