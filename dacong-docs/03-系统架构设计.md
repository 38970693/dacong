## 1. 整体架构

### 1.1 架构图

```
┌─────────────────────────────────────────────────────────────┐
│                      客户端层 (Flutter)                      │
│         场景选择 → 推荐展示 → 详情查看 → 分享传播           │
│              Web / Android / iOS 跨平台支持                  │
└─────────────────────────────────────────────────────────────┘
                              ↓ HTTPS
┌─────────────────────────────────────────────────────────────┐
│                      API层 (Supabase)                        │
│    PostgreSQL 15 + PostgREST + Realtime + Auth + Storage    │
│                     Row Level Security (RLS)                 │
└─────────────────────────────────────────────────────────────┘
                              ↓
        ┌─────────────────────┼─────────────────────┐
        ↓                     ↓                     ↓
┌──────────────────┐  ┌──────────────────┐  ┌──────────────────┐
│   爬虫层 (VPS)    │  │  AI生成层 (VPS)   │  │  审核层 (Web)     │
│   Python 3.11+   │  │  Claude API      │  │  Next.js         │
│   数据采集       │  │  内容生成        │  │  人工审核        │
│   定时任务       │  │  质量检测        │  │  快捷操作        │
└──────────────────┘  └──────────────────┘  └──────────────────┘
```

### 1.2 数据流

```
1. 数据采集
   爬虫 → raw_data表 (原始数据)
   
2. AI生成
   raw_data → AI分析 → generated_content表 (待审核)
   
3. 人工审核
   generated_content → 人工审核 → published_content表 (已发布)
   
4. 客户端展示
   published_content → Flutter客户端 → 用户
   
5. 反馈循环
   用户反馈 → user_feedback表 → 优化Prompt → 提升质量
```

```python
# 使用Redis去重
def is_duplicate(url):
    key = f"spider:seen:{hashlib.md5(url.encode()).hexdigest()}"
    if redis.exists(key):
        return True
    redis.setex(key, 86400, 1)  # 24小时过期
    return False
```

#### 生成流程

```python
# 1. 数据准备
raw_data = fetch_from_supabase()

# 2. Prompt构建
prompt = PromptBuilder()
    .add_system_prompt(SYSTEM_PROMPT)  # 缓存
    .add_few_shot_examples(examples)   # 缓存
    .add_user_data(raw_data)           # 不缓存
    .build()

# 3. 多轮生成
draft = claude.generate(prompt)
critique = claude.critique(draft)
final = claude.improve(draft, critique)

# 4. 质量检测
quality_score = QualityChecker.check(final)
if quality_score < 0.8:
    regenerate()

# 5. 入库
save_to_supabase(final, quality_score)
```

#### 审核策略

```typescript
// 自动发布条件
function shouldAutoPublish(content: GeneratedContent): boolean {
  return (
    content.ai_confidence > 0.85 &&
    content.quality_score > 0.8 &&
    !hasSensitiveWords(content) &&
    content.data_completeness > 0.9 &&
    !isDuplicate(content)
  );
}

// 智能排序
function sortReviewQueue(items: GeneratedContent[]): GeneratedContent[] {
  return items.sort((a, b) => {
    let scoreA = 0;
    let scoreB = 0;
    
    // AI置信度低 → 优先审核
    if (a.ai_confidence < 0.85) scoreA += 10;
    if (b.ai_confidence < 0.85) scoreB += 10;
    
    // 高热度话题 → 优先审核
    if (a.trending_score > 0.8) scoreA += 7;
    if (b.trending_score > 0.8) scoreB += 7;
    
    return scoreB - scoreA;
  });
}
```

## 5. 数据安全

### 5.1 认证与授权

**Supabase Auth：**
- 支持邮箱/密码、OAuth（Google、GitHub）
- JWT Token认证
- 自动刷新Token

**Row Level Security (RLS)：**
```sql
-- 用户只能看到已发布的内容
CREATE POLICY "Public content is viewable by everyone"
ON published_content FOR SELECT
USING (true);

-- 用户只能修改自己的反馈
CREATE POLICY "Users can update own feedback"
ON user_feedback FOR UPDATE
USING (auth.uid() = user_id);

-- 管理员可以审核内容
CREATE POLICY "Admins can review content"
ON generated_content FOR ALL
USING (auth.jwt() ->> 'role' = 'admin');
```

### 5.2 数据加密

- **传输加密**：HTTPS/TLS 1.3
- **存储加密**：Supabase自动加密
- **敏感数据**：环境变量存储（不提交到Git）

### 5.3 API安全

- **Rate Limiting**：每IP每分钟60次请求
- **CORS**：只允许特定域名
- **API Key**：Supabase Service Role Key仅后端使用
