# 产品需求文档 (PRD)

## 1. 产品概述

**产品名称：** DaCong（大聪）

**产品定位：** AI 模型排行与社区平台，帮助用户发现优质 AI 模型、学习提示词技巧、交流使用经验。

**核心价值：**
- 真实榜单 — 基于 GitHub/HuggingFace/HN 等公开数据的客观排行
- 社区交流 — 模型评测分享、提示词工作流交流
- 知识赋能 — 提示词广场、组合技教程

---

## 2. 目标用户

| 用户画像 | 需求 |
|---------|------|
| AI 开发者 | 找模型、看趋势、对比性能 |
| AI 爱好者 | 学提示词、看评测、参与讨论 |
| 企业采购 | 选型参考、成本评估 |

---

## 3. 功能清单

### 3.1 快讯 / 首页

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 热点流 | 聚合 HN/PH/AI KOL 的 AI 相关快讯 | P0 |
| 热搜词 | 基于搜索日志计算的实时热搜 TOP10 | P1 |
| 每日卡片 | 每日推荐一个有趣模型/工具 | P1 |

### 3.2 排行榜

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 综合榜 | 按综合权重排名的 AI 模型列表 | P0 |
| 分类榜 | LLM / VLM / TTS / Embedding 分类排行 | P0 |
| 盲测对决 | 两个模型 PK，用户投票，实时更新胜率 | P1 |
| 模型详情卡 | 厂商/价格/标签/趋势图 | P0 |

### 3.3 赋能学习

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 提示词广场 | 用户上传/浏览/收藏提示词 | P0 |
| 组合技教程 | 多模型串联的工作流教程 | P1 |
| 模型跳转 | 一键跳转厂商官网/API调试页 | P0 |

### 3.4 社区交流

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 帖子流 | 关注/推荐混合的帖子列表 | P0 |
| 评论/点赞/收藏 | 基础互动功能 | P0 |
| 话题圈 | 按话题分类的帖子聚合 | P1 |
| 私信 | 用户间私聊，支持分享提示词卡片 | P2 |

### 3.5 个人中心

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 收藏/历史 | 我的收藏和浏览历史 | P0 |
| 订阅管理 | 订阅模型/话题/关键词的更新通知 | P1 |
| 设置 | 通知/隐私/主题设置 | P1 |

---

## 4. 用户旅程

### 新用户
1. 打开 App → 看到快讯流和今日推荐
2. 浏览排行榜 → 找到感兴趣模型 → 查看详情
3. 进入赋能页 → 收藏提示词 → 尝试使用
4. 参与社区 → 发帖/评论 → 关注其他用户

### 回访用户
1. 打开 App → 查看热搜词和榜单变化
2. 收到推送通知（订阅模型更新） → 点击进入详情
3. 参与评论/讨论
