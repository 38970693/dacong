> 版本：v2.0  
> 更新日期：2026-04-17  
> 产品定位：AI工具决策助手（从"社区平台"调整为"决策助手"）

---

## 1. 产品概述

### 1.1 产品定位

**DaCong（大聪）** 是一个AI工具决策助手，通过场景化推荐、详细教程和精选周报，帮助用户在3分钟内找到最适合的AI工具。

### 1.2 核心价值

- **解决选择困难**：模型太多不知道选哪个 → 场景化推荐直接给答案
- **降低使用门槛**：安装复杂普通人不会 → 傻瓜式教程一步步指导
- **节省筛选时间**：信息过载看不过来 → 精选周报只看最重要的

### 1.3 目标用户

1. **开发者**（核心用户）：需要选AI编程助手、对比工具
2. **内容创作者**：需要做视频/图片的AI工具
3. **AI爱好者**：想了解AI最新动态

## 2. MVP功能清单

### 2.1 核心功能（P0 - 必须做）

#### 功能1：场景化推荐

**用户故事：**
> 作为一个开发者，我想知道写代码用哪个AI工具最好，这样我就不用自己一个个试了。

**功能描述：**
- 首页展示常见场景（写代码、做视频、做图片、日常对话）
- 点击场景后，展示3个推荐（最佳、平替、免费）
- 每个推荐包含：
  - 工具名称
  - 一句话描述
  - 优点（2-3个）
  - 缺点（1-2个）
  - 适合人群
  - 价格
  - 访问方式（国内可用/需翻墙）
  - 推荐指数（1-5星）

**验收标准：**
- [ ] 支持至少4个场景
- [ ] 每个场景至少3个推荐
- [ ] 推荐内容准确、有依据
- [ ] 加载时间 < 2秒

**优先级：** P0（第1周完成）

---

#### 功能2：工具详情页

**用户故事：**
> 作为一个用户，我想查看工具的详细信息，这样我就能决定是否使用它。

**功能描述：**
- 基本信息（名称、厂商、官网、GitHub）
- 详细介绍（功能、特点、使用场景）
- 价格信息（免费/付费、具体价格）
- 访问方式（国内可用/需翻墙、安装难度）
- 用户评价（有用/无用统计）
- 相关推荐（类似工具）

**验收标准：**
- [ ] 信息完整、准确
- [ ] 支持用户反馈（有用/无用）
- [ ] 相关推荐至少3个

**优先级：** P0（第1周完成）

---

#### 功能3：安装教程

**用户故事：**
> 作为一个普通用户，我想看到详细的安装教程，这样我就能自己安装工具。

**功能描述：**
- 分步骤教程（每步有标题、命令、注意事项）
- 标注难度（简单/中等/困难）
- 标注时间（预计10分钟）
- 前置条件（需要Node.js、Python等）
- 常见问题解答（FAQ）
- 绿色版/Docker版推荐（如果有）

**验收标准：**
- [ ] 教程清晰易懂
- [ ] 普通用户能按教程完成安装
- [ ] 覆盖常见问题

**优先级：** P0（第2周完成）

---

#### 功能4：每周精选周报

**用户故事：**
> 作为一个AI爱好者，我想每周看到最值得关注的AI项目，这样我就不会错过重要信息。

**功能描述：**
- 每周发布一期周报
- 包含5-10个精选项目
- 每个项目包含：
  - 项目名称
  - 一句话亮点
  - 为什么值得关注
  - GitHub链接
  - Star增长趋势
- 支持分享（生成图卡）

**验收标准：**
- [ ] 每周五发布
- [ ] 内容质量高（用户有用率 > 70%）
- [ ] 支持分享到社交平台

**优先级：** P0（第3周完成）

## 3. 不做什么（明确边界）

### 3.1 不做社区功能（短期）

**原因：**
- 社区需要大量用户才能活跃
- 内容审核成本高
- 与核心定位（决策助手）不符

**替代方案：**
- 用户评价（简单的点赞/评论）
- 外部社区链接（Reddit、Discord）

---

### 3.2 不做模型训练/部署

**原因：**
- 技术门槛高
- 成本高
- 不是核心价值

**替代方案：**
- 推荐第三方部署服务
- 提供部署教程

---

### 3.3 不做API市场（短期）

**原因：**
- 需要建立信任和用户基础
- 交易系统复杂
- 法律合规问题

**替代方案：**
- 推荐官方API
- 联盟推广（返佣）

## 4. 用户旅程

### 4.1 新用户首次使用

```
1. 打开App
   ↓
2. 看到首页（场景选择）
   - 写代码
   - 做视频
   - 做图片
   - 日常对话
   ↓
3. 点击"写代码"
   ↓
4. 看到推荐列表
   - 🥇 Claude Code（最佳）
   - 🥈 Cursor + DeepSeek（平替）
   - 🥉 GitHub Copilot Free（免费）
   ↓
5. 点击"Cursor + DeepSeek"
   ↓
6. 看到详情页
   - 基本信息
   - 优缺点
   - 价格
   - 安装教程
   ↓
7. 点击"查看安装教程"
   ↓
8. 按步骤安装
   ↓
9. 安装成功，点击"有用"反馈
   ↓
10. 收藏该工具
```

**关键指标：**
- 首页→推荐页转化率 > 80%
- 推荐页→详情页转化率 > 50%
- 详情页→教程页转化率 > 30%
- 用户反馈"有用"率 > 70%

## 6. 技术实现概要

### 6.1 数据来源

**爬虫自动采集：**
- GitHub Trending（每小时）
- HuggingFace Models（每6小时）
- OpenRouter API价格（每小时）
- Reddit/Twitter讨论（每天）
- Benchmark榜单（每周）

### 6.2 内容生成

**AI自动生成：**
- 使用Claude 3.5 Sonnet API
- 多轮生成（初稿→批评→改进）
- 结构化输出（JSON格式）
- 质量检测（置信度、完整性）

### 6.3 人工审核

**审核策略：**
- 自动发布：AI置信度 > 0.85
- 人工审核：AI置信度 < 0.85 或随机抽查10%
- 审核时间：每天5小时，可审核50条

### 6.4 客户端展示

**技术栈：**
- Flutter（跨平台）
- Riverpod（状态管理）
- Supabase（后端）

## 8. 风险与应对

### 8.1 产品风险

**风险：用户不认可AI生成的内容**
- 应对：人工审核保证质量，收集用户反馈持续优化

**风险：内容同质化，竞品抄袭**
- 应对：建立内容护城河（AI生成速度快），注重用户体验

**风险：用户增长缓慢**
- 应对：内容营销、社交裂变、SEO优化

### 8.2 技术风险

**风险：AI API成本过高**
- 应对：Prompt Caching降低成本，混合方案（本地模型+Claude）

**风险：爬虫被封禁**
- 应对：使用官方API，遵守robots.txt，分布式爬虫

**风险：数据库性能瓶颈**
- 应对：Supabase自动扩容，优化查询，添加缓存
