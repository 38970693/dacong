# 技术方案设计

## 1. 系统架构

```
┌─────────────────────────────────────────────────────────────────┐
│                        客户端层 (Flutter)                        │
│         私信 Realtime / 榜单 30s 轮询 / 帖子流混合 / FCM 推送      │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│                      主后端层 (Supabase)                         │
│   PostgreSQL 15 / Realtime / Edge Functions / Auth / Storage    │
└─────────────────────────────────────────────────────────────────┘
                                │
              ┌─────────────────┼─────────────────┐
              ▼                 ▼                 ▼
┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐
│   爬虫层 (VPS)   │  │  外部 Worker    │  │   FCM 推送      │
│  只写 raw 表     │  │  AI审核/趋势计算 │  │   消息推送      │
└─────────────────┘  └─────────────────┘  └─────────────────┘
```

## 2. 技术选型

### 客户端
| 技术 | 选择 | 理由 |
|------|------|------|
| 跨平台框架 | Flutter | 一套代码覆盖 iOS/Android/Web |
| 状态管理 | Riverpod | 编译时安全、社区活跃 |
| 路由 | go_router | 声明式路由、支持 deep link |
| HTTP | dio | 拦截器、适配器完善 |
| 本地存储 | shared_preferences + hive | 轻量 + 结构化数据 |

### 后端
| 技术 | 选择 | 理由 |
|------|------|------|
| BaaS | Supabase | Auth+DB+Realtime+Storage 一站式 |
| Edge Functions | Deno | 触发器驱动、冷启动快 |
| AI 审核 | OpenAI Moderation API | 成本低、效果好 |
| 推送 | FCM (Firebase Cloud Messaging) | 免费、全平台支持 |

### 爬虫
| 技术 | 选择 | 理由 |
|------|------|------|
| 语言 | Python 3.11+ | 生态丰富、爬虫库多 |
| HTTP | httpx | 异步、支持 HTTP/2 |
| HTML 解析 | BeautifulSoup4 + lxml | 稳定、简单 |
| JS 渲染 | Playwright | Headless 浏览器 |
| 调度 | APScheduler | 轻量、定时任务 |

## 3. 部署方案

### Supabase Cloud（初期）
- 免费额度：500MB 数据库 / 2GB 存储 / 50万 MAU
- 按需升级：Pro $25/月 → 8GB / 100GB / 250万 MAU

### VPS（爬虫 + Worker）
- 推荐配置：2核4G / 50GB SSD / 独立 IP
- 系统：Ubuntu 22.04 LTS
- 预计成本：$10-20/月

### CI/CD
- GitLab CI/CD（代码已在 GitLab）
- 客户端：自动构建 Flutter Web APK
- 后端：自动部署 Edge Functions

## 4. 安全设计

### 数据安全
- RLS（行级安全策略）保护用户数据
- 敏感操作需 Supabase Service Role Key（仅后端使用）
- Edge Functions 内验证 JWT

### 内容安全
- 关键词过滤（实时）
- AI 审核（异步）
- 人工复核队列（高风险内容）

## 5. 性能目标

| API 响应 (P95) | < 500ms |
