# 数据库设计文档

## ER 概览

```
用户 (profiles) ──┬── 帖子 (posts)
                 ├── 评论 (comments)
                 ├── 点赞 (likes)
                 ├── 收藏 (favorites)
                 └── 订阅 (subscriptions)

模型 (models) ────┬── 原始指标 (model_raw_metrics)
                  └── 排名 (model_ranks)

快讯 (hot_news_raw) ──→ 热搜词 (trending_keywords)

内容 ──→ 审核队战 (moderation_queue) ──→ AI Worker 处理
```

## 表结构

### 1. profiles（用户表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | UUID | PK, FK(auth.uid) | 用户ID |
| username | VARCHAR(50) | UNIQUE, NOT NULL | 用户名 |
| avatar_url | TEXT | | 头像URL |
| bio | TEXT | | 个人简介 |
| created_at | TIMESTAMPTZ | DEFAULT now() | 创建时间 |
| updated_at | TIMESTAMPTZ | DEFAULT now() | 更新时间 |

### 2. models（AI模型表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | UUID | PK | 模型ID |
| name | VARCHAR(200) | NOT NULL | 模型名称 |
| vendor | VARCHAR(100) | NOT NULL | 厂商（OpenAI/Anthropic/开源） |
| category | VARCHAR(50) | NOT NULL | 类别（LLM/VLM/TTS/Embedding） |
| description | TEXT | | 模型描述 |
| website_url | TEXT | | 官网链接 |
| api_endpoint | TEXT | | API地址 |
| pricing_url | TEXT | | 价格页 |
| is_open_source | BOOLEAN | DEFAULT false | 是否开源 |
| tags | TEXT[] | | 标签数组 |
| created_at | TIMESTAMPTZ | DEFAULT now() | |

### 3. model_raw_metrics（原始指标）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGSERIAL | PK | |
| model_id | UUID | FK(models.id) | 关联模型 |
| source | VARCHAR(50) | NOT NULL | 数据来源 |
| metric_type | VARCHAR(50) | NOT NULL | 指标类型 |
| metric_value | JSONB | | 原始值 |

- `idx_metrics_model_source` ON (model_id, source)

### 4. model_ranks（模型排名）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGSERIAL | PK | |

### 5. posts（帖子）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | UUID | PK | |
| user_id | UUID | FK(profiles.id), NOT NULL | 作者 |
| title | VARCHAR(200) | NOT NULL | 标题 |
| content | TEXT | NOT NULL | 正文 |

### 11. hot_news_raw（快讯原始数据）

| 字段 | 类型 | 约束 | 说明 |

## RLS 策略

所有用户数据表启用 Row Level Security：

- profiles: 公开读取，本人可更新
- posts: 所有人可读，作者可修改
- comments: 所有人可读，作者可修改
- likes/favorites: 仅本人可见
- subscriptions: 仅本人可见

## 触发器

1. **posts AFTER INSERT** → 写入 moderation_queue
2. **posts AFTER INSERT** → 更新 topics.post_count
3. **likes AFTER INSERT/DELETE** → 更新 posts.like_count
4. **comments AFTER INSERT** → 更新 posts.comment_count
