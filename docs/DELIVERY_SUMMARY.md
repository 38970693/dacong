## 🏗️ 技术架构亮点

### 1. 生产就绪工程架构

**安全架构**:
```
用户请求
  ↓
CDN + WAF（DDoS防护）
  ↓
CSRF Token验证
  ↓
输入验证（Zod Schema）
  ↓
业务逻辑层
  ↓
数据加密存储
```

**监控架构**:
```
应用层（客户端、管理后台、爬虫）
  ↓
Sentry（错误监控）+ Grafana（性能监控）+ Loki（日志聚合）
  ↓
告警系统（Email/Slack）
```

**部署架构**:
```
GitLab CI/CD
  ↓
Test → Lint → Security → Build → Deploy
  ↓
Docker Registry
  ↓
容器化部署（客户端、管理后台、爬虫）
  ↓
Supabase（数据库+Auth）
```

### 3. AI增强系统架构

**推荐引擎**:
```
用户请求
  ↓
推荐调度器
  ├─ 协同过滤推荐（40%）
  ├─ 内容推荐（40%）
  └─ 热门推荐（20%）
  ↓
结果融合器（加权排序）
  ↓
推荐结果
```

**智能搜索**:
```
用户查询
  ↓
查询理解（意图识别、实体提取）
  ↓
Embedding生成（OpenAI API）
  ↓
向量检索（pgvector）
  ↓
结果排序（相关性+质量+时效性）
  ↓
搜索结果
```

**AI审核**:
```
用户内容
  ↓
规则检测（快速过滤）
  ↓
AI检测（OpenAI Moderation）
  ↓
人工复审（可疑内容）
  ↓
审核结果
```
