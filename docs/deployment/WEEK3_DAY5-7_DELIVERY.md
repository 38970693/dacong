## 📝 部署说明

### 前置条件
1. Flutter SDK 3.0+
2. Supabase 项目已创建
3. 数据库表已创建

### 部署步骤

#### 1. 数据库迁移
```bash
cd dacong-api
supabase db push
```

#### 2. 部署 API
```bash
supabase functions deploy get-realtime-stats
supabase functions deploy get-trend-data
```

#### 3. 前端构建
```bash
cd dacong-admin
flutter pub get
flutter build web --release
```

#### 4. 验证部署
- 访问数据看板页面
- 检查图表显示
