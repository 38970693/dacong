# AI 作品与创意广场

更新：2026-11-03。

现有新闻保留在 `/web/dynamics`。新增桌面及手机导航“作品”，入口 `/web/works`，分享页 `/web/works/new`，详情 `/web/works/[id]`。

第一版支持：

- 浏览全部、可体验作品或创意提案，按最新排序，加载更多及刷新。
- 作品填写体验链接，可选源码链接；创意不要求已经有体验地址。
- 分享标题、简介、实现说明及公开昵称。内容以普通文本展示，不执行用户脚本或嵌入外部页面。
- 登录后发布，成功后进入详情；分享者可以撤回自己的内容。
- 体验及源码通过 HTTPS 外部链接打开，保留新闻页和原有功能。

数据位于独立的 `ai_showcases` 表，迁移为 `20261103_00008_ai_showcases.sql`。使用现有 Supabase 登录会话，浏览器只使用公开 anon 配置。数据库 RLS 允许公开读取已发布内容、用户发布自己的内容、分享者撤回；插入列权限禁止指定状态和创建时间，更新权限仅允许修改发布状态。作者 ID 来自实际登录用户，不公开登录邮箱。

没有预置或虚构用户作品。当前不包含截图上传、站内运行用户代码、点赞、评论、协作募集、编辑已发布内容或专用管理员审核界面。Android 完整版加载同一站点，可以直接显示新增页签；APK 内置新闻简版暂不包含作品广场。

验证：新增 8 项验证与交互测试；`supabase/tests/showcases_rls.sql` 在事务中验证真实权限和发布、撤回，所有临时用户及内容均回滚。
