# DaCong v2.1 开发计划

**制定日期**: 2026-05-06
**目标版本**: v2.1
**预计周期**: 2-4 周

---

## 📋 Sprint 规划

### Sprint 1: 核心交互 (1-2 周)

#### 1. 评论系统 ⭐ P0

**功能点**:
- [ ] 评论表设计 (`comments` 表)
- [ ] 评论 API (`/api/comments`)
- [ ] 评论组件 (显示、回复、嵌套)
- [ ] 帖子详情页集成评论
- [ ] 评测详情页集成评论

**技术方案**:
```
表结构:
- id: UUID
- target_type: 'post' | 'review'
- target_id: string
- user_id: string
- content: string
- parent_id: UUID | null (支持嵌套)
- likes: number
- created_at, updated_at
```

#### 2. 点赞功能 ⭐ P0

**功能点**:
- [ ] 点赞 API (`/api/likes`)
- [ ] 帖子点赞按钮
- [ ] 评测点赞按钮
- [ ] 模型点赞按钮

---

### Sprint 2: 国际化与 PWA (1-2 周)

#### 3. 国际化 (i18n) ⭐ P1

**技术方案**: next-intl 或自定义方案

**需要翻译的内容**:
- UI 文本 (按钮、标签、提示)
- 页面标题和描述
- 错误消息
- 时间格式化 (相对时间)

**文件结构**:
```
src/locales/
├── zh.json
└── en.json
```

#### 4. PWA 支持 ⭐ P1

**功能点**:
- [ ] Web App Manifest
- [ ] Service Worker (workbox)
- [ ] 离线页面
- [ ] 安装提示

---

### Sprint 3: 社区功能 (可选)

#### 5. 关注体系 ⭐ P1

**表结构**:
```
- follows: user_id, following_id, created_at
- 用户主页: 显示关注/粉丝数
- 关注按钮: 关注/取消关注
```

#### 6. 通知系统 ⭐ P1

**功能点**:
- [ ] 通知表设计
- [ ] 通知 API
- [ ] 通知列表页面
- [ ] WebSocket 实时通知 (可选)
