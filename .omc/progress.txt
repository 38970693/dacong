## 学习记录

### 代码模式
- Next.js API 路由使用 Supabase 直接连接
- API 响应格式: `{ success, data?, error? }`
- 使用 NextResponse.json 返回响应
- 使用 Promise<{ params }> 处理动态路由参数（Next.js 15+）

### 问题解决
- 使用单例模式复用 Supabase 客户端
- 动态路由参数在 Next.js 15+ 变为 Promise 类型
- Flutter CommentModel 需要同时支持 Edge Functions 和 REST API 格式
