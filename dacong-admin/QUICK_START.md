# 批量操作功能 - 快速开始

## 立即使用

批量操作功能已经集成到以下页面，无需额外配置即可使用：

### 1. 内容管理页面

**路径**: 管理后台 → 内容管理

**操作步骤**:
1. 勾选需要操作的内容项（点击复选框）
2. 或点击"全选"按钮选择当前页所有内容
3. 在顶部 AppBar 选择操作：
   - **批量通过**: 一键通过所有选中内容
   - **批量拒绝**: 一键拒绝所有选中内容
   - **批量删除**: 删除选中内容（需确认）
   - **批量导出**: 导出为 CSV 文件
4. 查看进度对话框（批量操作时自动显示）
5. 完成后自动刷新列表

### 2. 评论审核页面

**路径**: 管理后台 → 评论审核

**操作步骤**:
1. 勾选需要操作的评论（点击复选框）
2. 或点击"全选"按钮选择当前页所有评论
3. 在顶部 AppBar 选择操作：
   - **批量通过**: 一键通过所有选中评论
   - **批量删除**: 删除选中评论
     - 可填写删除原因
     - 可选择同时封禁用户
4. 查看进度对话框
5. 完成后自动刷新列表

## 功能特点

✅ **智能进度显示**
- 单个操作：直接执行，快速反馈
- 批量操作：显示进度对话框，实时更新

✅ **安全确认机制**
- 删除操作需要二次确认
- 显示将要操作的项数
- 防止误操作

✅ **实时反馈**
- 进度百分比显示
- 当前处理项预览
- 操作成功/失败提示

✅ **性能优化**
- 请求间隔控制（100ms）
- 避免服务器压力
- 流畅的用户体验

## 键盘快捷键

- `1` - 通过当前内容
- `2` - 拒绝当前内容
- `E` - 编辑当前内容
- `N` - 下一条内容

## 常见问题

### Q: 如何取消选择？
A: 点击顶部的"取消选择"按钮，或再次点击"全选"按钮。

### Q: 批量操作会一次性发送所有请求吗？
A: 不会。批量操作会逐个处理，每个请求间隔 100ms，避免服务器压力。

### Q: 操作失败了怎么办？
A: 系统会显示错误信息，其他项不受影响。可以重新选择失败的项再次操作。

### Q: 可以中途取消批量操作吗？
A: 当前版本不支持中途取消，但操作失败会自动停止。未来版本会添加取消功能。

### Q: 批量删除评论时，封禁用户是什么意思？
A: 勾选"同时封禁用户"后，系统会封禁这些评论的作者，防止他们继续发布违规内容。

### 快速集成示例

```dart
import '../widgets/batch_selection_widget.dart';

// 在你的页面中
final Set<String> _selectedIds = {};

// 使用批量操作对话框
final success = await BatchOperationDialog.show(
  context: context,
  title: '批量处理',
  totalCount: _selectedIds.length,
  operation: (updateProgress) async {
    final ids = _selectedIds.toList();
    for (int i = 0; i < ids.length; i++) {
      updateProgress(i, '处理项 ${i + 1}');
      await yourApiCall(ids[i]);
      if (i < ids.length - 1) {
        await Future.delayed(Duration(milliseconds: 100));
      }
    }
    updateProgress(ids.length, null);
  },
);

if (success) {
  // 操作成功
}
```
