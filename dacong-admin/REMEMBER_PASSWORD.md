# 记住密码功能使用说明

## 功能说明

登录页面已添加"记住密码"功能：

### 界面变化
- 密码输入框下方新增"记住密码"复选框
- 勾选后登录成功会保存账号密码
- 下次打开页面会自动填充

### 使用步骤

1. 输入邮箱和密码
2. 勾选"记住密码"
3. 点击"登录"按钮
4. 下次打开页面会自动填充账号密码

### 取消记住密码

1. 取消勾选"记住密码"
2. 再次登录
3. 保存的账号密码会被清除

## 安全说明

- 密码保存在本地浏览器的 localStorage 中
- 仅在本机有效
- 清除浏览器数据会删除保存的密码
- 建议仅在个人设备上使用此功能

## 热重启应用

在 Flutter 控制台按 `R` 键（大写）进行热重启，然后刷新浏览器页面即可看到新功能。
