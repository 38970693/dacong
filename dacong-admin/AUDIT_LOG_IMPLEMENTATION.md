# 操作日志功能实现文档

## 概述
为 DaCong 管理后台实现了完整的操作日志功能，用于记录和查询管理员的所有操作行为。

## 实现的功能

### 1. 数据模型 (`lib/models/audit_log.dart`)
- **AuditLog 类**: 操作日志数据模型
  - 字段: id, userId, username, avatarUrl, action, resource, ip, details, createdAt
  - 自动标签转换: actionLabel (操作类型中文), resourceLabel (资源类型中文)
  - 支持的操作类型: 审核内容、编辑内容、删除内容、封禁用户、解封用户、删除用户、审核评论、删除评论、登录、登出
  - 支持的资源类型: 内容、用户、评论、系统

- **AuditLogFilter 类**: 日志筛选条件
  - 支持按用户、操作类型、资源类型、时间范围筛选
  - 提供 copyWith 方法便于更新筛选条件
  - hasFilters 属性判断是否有激活的筛选条件

### 2. 服务层 (`lib/services/audit_log_service.dart`)
- **getAuditLogs()**: 获取操作日志列表
  - 支持分页加载 (默认每页 50 条)
  - 支持多维度筛选
  - 返回格式化的 AuditLog 对象列表

- **exportLogsToCSV()**: 导出日志为 CSV 格式
  - 支持大数据量导出 (默认最多 10,000 条)
  - 分页批量获取数据避免内存溢出
  - CSV 包含: 时间、操作人、操作类型、资源类型、IP地址、详情
  - 自动格式化日期时间和详情字段

- **getActionTypes()**: 获取所有可用的操作类型
- **getResourceTypes()**: 获取所有可用的资源类型

### 3. 页面 (`lib/pages/audit_logs_page.dart`)
- **筛选功能**:
  - 操作类型下拉选择
  - 资源类型下拉选择
  - 时间范围选择器 (DateRangePicker)
  - 一键清除所有筛选条件
  - 刷新按钮

- **日志列表展示**:
  - DataTable 展示日志数据
  - 显示字段: 时间、操作人(含头像)、操作类型(彩色标签)、资源类型、IP地址、详情按钮
  - 操作类型颜色编码:
    - 红色: 删除、封禁操作
    - 橙色: 编辑、审核操作
    - 绿色: 登录、解封操作
    - 蓝色: 其他操作

- **分页功能**:
  - 每页显示 50 条记录
  - 上一页/下一页按钮
  - 显示当前页码、总页数、总记录数

- **导出功能**:
  - 导出按钮带加载状态指示
  - 导出文件名包含时间戳: `audit_logs_YYYYMMDD_HHmmss.csv`
  - 导出完成后显示成功提示

- **详情查看**:
  - 点击详情按钮弹出对话框
  - 以键值对形式展示操作详情
  - 支持滚动查看长内容

### 4. 路由集成 (`lib/main.dart`)
- 添加 `/audit-logs` 路由
- 在侧边栏添加"操作日志"导航项 (历史图标)
- 自动路由选中状态管理

## 使用说明

### 查看操作日志
1. 登录管理后台
2. 点击侧边栏"操作日志"
3. 查看所有管理员操作记录

### 筛选日志
1. 选择操作类型 (如"审核内容")
2. 选择资源类型 (如"内容")
3. 点击"选择时间范围"选择日期区间
4. 系统自动刷新符合条件的日志

### 导出日志
1. 设置需要的筛选条件 (可选)
2. 点击右上角导出按钮
3. 等待导出完成
4. 文件保存到应用文档目录

### 查看详情
1. 找到目标日志记录
2. 点击"详情"图标按钮
3. 在弹出对话框中查看完整操作详情
